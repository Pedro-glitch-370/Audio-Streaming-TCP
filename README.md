# Audio-Streaming-TCP
A client-server distributed system built in Python for real-time audio streaming over TCP sockets.

OBS: Essa branch é apenas para testar e visualizar de forma simples com o projeto deve ser!

# Como testar
- Abra dois terminais: um para o Server e um para o Client
- Inicie o server com python server/socket_server
- Inicie o client com python client/client_server
- Deve aparecer o áudio "received_sample" no diretório de áudio
